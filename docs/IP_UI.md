# 公网 IP 管理界面

服务器列表和详情中的「公网 IP」入口按账号、地区及实例 ID 读取 `/api/ip`。界面使用适配器回读的 `primaryIPv4`、`addresses`、`serviceIPv4` 和 `methods`，分别显示原始地址、额外或 Reserved 地址、实际对外服务地址及每种方式当前是否可用。不可用方式保留原因，不提供提交入口。DigitalOcean Reserved IP 明示为额外服务地址，不宣称原始 Droplet IPv4 已变化。

手动「检测 IP」只使用当前详情列出的地址。打开检测设置时才读取探针；协议、端口、SNI/HTTP Host、路径、超时、间隔与连续阈值随任务送到 `/api/ip/check`。自动换 IP 始终关闭。检测记录在「国内连通性」显示，与自动筛选任务区分。探针的「停用」保留记录，「删除探针」调用独立 DELETE 接口；历史任务由后端保存。

手动换 IP 按云端提供的可用方法提交 `ipChange`，携带快照和已选的现有地址绑定信息。操作按钮展示停机、费用与旧 IP 风险，沿用 `/api/confirm` 和 `/api/jobs` 的一次确认与同请求 ID 重试。可选换后检测使用同一检测设置。任务页显示回读后的地址变化、原始 IP 是否改变、相同 IP 再次分配以及可能需要来宾系统网络配置的提醒。需要新原始实例时，「创建替代实例」进入普通创建表单，预填地区和新名称；旧实例不会被自动删除。

`NARBE_BROWSER_TEST=1 go test ./internal/app -run TestBrowserIPManagement -v` 使用真实 Go 登录与嵌入页面，通过 HTTP 测试替身提供四云 IP 能力、探针和任务结果，并在桌面及手机视口截图。该测试不发起真实云写。真实云能力、账单和中国大陆探针联调仍需在授权环境验收。

## UI 判断
新项目 / 运维工作台。单用户管理自己的云账号和服务器。首要对象为账号、服务器、操作任务。
流程：登录 → 接入云账号 → 刷新地区/服务器 → 选择地区/规格/镜像 → 审核配置与费用风险 → 提交 → 任务结果。
采用原生语义 HTML、CSS 设计变量、ES modules 与 dialog；无需前端服务与构建依赖。
参考成熟云控制台的信息密度与 GOV.UK 表单错误恢复原则，独立设计蓝灰/暖白界面。
桌面侧栏+资源表；移动端优先账号、创建与任务状态，可横向浏览表格。
必须包含加载/空/错误/执行中/结果未知状态，删除需要输入实例名称。
不在界面呈现实现说明、密钥、原始技术日志；错误译为行动建议。
验证：API 集成测试、真实浏览器操作与桌面/手机截图检查。

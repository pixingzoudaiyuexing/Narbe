# 国内公网 IPv4 连通性自动筛选（开发候选）

基线为已发布的 `v0.1.0-beta.5` / `80d326fa5ddbd777709a023825d171d3fd69e0ff`。本功能是后续独立开发候选，尚未发布、合并或部署 Owner 环境。管理端仍为 Go + SQLite 单容器，探针为无云凭据的出站 HTTPS 单容器。不会增加账号或服务器业务锁，不提供 DNS 切换、VPS 代理或商业化功能。

## 使用流程

1. 管理端须有可信证书的 HTTPS Origin。按 [Probe 部署说明](PROBE.md) 部署中国大陆探针；也可部署海外对照探针。
2. 在「国内连通性」登记探针用途及**实际公网出口 IPv4**，一次性凭据有效 5 分钟。国内探针必须在线、报告新鲜 CN 出口，且经管理端独立查询核实；管理端本身只能在出口确认为非 CN 时充当海外对照。
3. 创建服务器时默认关闭检测。启用后指定探针、TCP/TLS/HTTP/HTTPS、同一目标端口、超时、间隔、连续成功/失败次数和就绪等待时间。
4. 必须已有监听服务，例如镜像提供的 SSH，或用户原来的初始化脚本部署的健康端点。不会覆盖 Cloud-init / Metadata / StackScript，也不会自动注入健康服务。没有有效目标时显示未就绪，绝不把端口未监听当作 IP 被墙。
5. HTTP 可配置本次随机挑战，健康服务须精确返回该值。TLS 正常校验证书与名称；证书错误、HTTP 状态不符、挑战不符、探针配置错误都只会暂停，不能据此删机。
6. 自动换 IP 需一次明确费用/删除风险授权。默认最多 5 轮；不同厂商一轮可能是原地换 IP，也可能删除本轮实例后重建，不代表每轮一定创建新 VM。
7. 任务页保留各轮准确资源 ID、地址、重复地址、检测结果/时间/延迟、换 IP 方式、云写意图与关联资源。停止仅停止后续云写，不删除仍存资源；关机已被受理的实例可能仍关机。所有现存实例、公网 IP、磁盘等仍可能计费。

## 判定与自动化

`queued → creating → waiting-ready → probing → accepted`，有充分失败证据时 `replacing → creating/waiting-ready`；也可进入 `paused / unknown / failed / exhausted / stopped`。

- 创建前先核实国内与海外出口。等待准确实例公网 IPv4，海外同 IP、同端口实际成功后才开始国内比较。
- 国内连续成功且对应海外成功才保留为 accepted；只证明指定时间和协议的可达性，不保证所有大陆运营商、所有端口或未来一直可用。
- 只有国内连续连接级 `timeout / connection_error` 且逐次对应海外成功，才能判为**疑似国内不可达**。这不是对封锁原因的鉴定，可能包含路由、运营商、ACL 等差异。未使用 ICMP 失败作裁决，本候选没有 ICMP 功能。
- 每份证据固定准确目标。最后一份国内证据最多 90 秒、海外最多 60 秒，海外检查在国内完成后进行；各次配对最多相差 60 秒。早先连续失败也须位于该轮就绪窗口中。写前再次核实当前 IP/资源指纹、探针出口及证据新鲜度；过期则暂停。
- 2 个独立筛选执行槽与原 4 个普通 Worker 并行；只对单工作流 CAS 领取，不以账号或服务器阻断其他操作。探针单并发，租约 90 秒；超过响应窗口不会算作国内失败。整个工作流检测历史上限 600，触及后保留历史并暂停；列表仅返回最近 20 个工作流，准确任务 ID 的详情接口仍可读取完整历史。
- 最大轮次 1–20，单次超时 1–15 秒，间隔 2–300 秒，连续阈值 2–10，每轮就绪 30–1800 秒，总时长最多 21600 秒。总时长、次数和停止标记在后续云写前再次检查。

## 费用、身份和恢复

费用上限采用用户填写的**每轮保守估算预留额**，以美分向上取整并在创建或下一轮换 IP 之前落盘预留；不会用未预留费用执行下一轮破坏性步骤。它既不读取即时云账单，也不保证实际总账单低于此值；存储、公网 IP、最低计费时段、流量、税费、延迟出账及任务结束后继续运行均可能另收费。停止或不确定时保留的预留不等于已经发生同额账单。

工作流加密固定原创建参数、密码/脚本、账号凭据及网络出口配置与 revision。每次云写临近 HTTP 派发前检查停止/期限/账号状态并保存意图。账号更新或移除会暂停该流程的后续云写，不影响其他请求；不复用更新后的凭据证明旧操作。

资源必须来自本轮精确创建 token、准确 ID、账号/订阅/资源组/地区及配置指纹。不得以名称找资源。外部修改导致无法核实时暂停；存在云端读写间隙，不宣称能禁止其他控制台并发操作。四云能力与附属资源约束详见 [厂商矩阵](CN_PROVIDER_SOURCES.md)。

所有 active 工作流重启后暂停，queued 授权不会跨停机自动执行；保留最后云写和资源账本。创建响应丢失、删除响应丢失、停启或换绑中断都不会重放云写。只能点击专用「只读核实」更新已知资源事实，不会自动继续创建、恢复遗漏步骤或把单个 VM running 当成整个流程成功。没有可信资源 ID 时需到云控制台按本轮标签/账本核实。没有自动“继续未知操作”按钮。

SQLite 迁移仅新增表，继续使用同一数据 Volume 和 master.key。升级前必须完整备份停止状态下的 `/data`（含 SQLite/WAL 与密钥）。旧 beta.5 不识别新工作流，不能把保留旧镜像等同于已证明新数据可无损降级；若回滚应恢复升级前完整备份，在隔离副本先验证。不可删除正式 Volume。

## 探针与网络边界

出站控制面使用独立 Bearer 身份，服务端只存令牌哈希。租约与 probe/task/target/time 精确绑定，完全相同结果幂等确认一次；不同结果或旧租约拒绝。探针持久化身份和已执行租约，失败结果先落盘再重试上传；不保存云账号密钥。

目标仅限本轮经适配器验证的规范公网 IPv4 与探针本地白名单端口。连接固定数值 IP，不解析目标 DNS、不跟随重定向、不继承 HTTP_PROXY/ALL_PROXY；拒绝 Metadata、私网、回环、CGNAT、保留/文档/组播及映射地址。响应体、头、超时、并发均有界。管理员不能通过探针 API 提交任意目标扫描。

固定 HTTPS Country.is 只提供 IP 地理归属证据，不能证明物理位置或全路径直连。分流 Clash/TUN/VPN 可能让地理服务与检测目标走不同线路；应使用受控国内 VPS 或明确关闭这类分流的网络。服务失败/国家未知/出口改变均停止判断。2026-11-15 的本机实测已发现 macOS 宿主出口为 CN，但 Docker Desktop 容器出口为 US；因此该容器不能仅凭 Mac 位于国内充当国内探针。Linux runner 的宿主 IPv4 与容器实际出口、容器接受测试由原生 CI 分开记录（宿主查询不可用则明确 unverified），不泛化为所有 Docker 网络行为。

## 构建与候选镜像

管理端、Probe 使用固定 Go 1.26.11 镜像 Digest。扫描实际发现旧 Go 1.26.10 存在 [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859)；此次最小升级修复，不改动 beta.5 正式镜像。

```bash
docker build --build-arg VERSION=cn-candidate -t narbe:cn-candidate .
docker build -f Dockerfile.probe --build-arg VERSION=cn-candidate -t narbe-probe:cn-candidate .
```

原生 AMD64 / ARM64 CI 分别导出 Probe image tar、SOURCE_SHA、镜像信息和 SHA256SUMS，作为开发候选交付（Actions Artifact 有保留期限）。校验后可 `docker load -i narbe-probe-linux-<arch>.tar`，再将该候选镜像标记为 `narbe-probe:cn-candidate` 使用 Compose。没有暗示正式 GHCR Probe 镜像或新 Narbe 版本已经发布。正式发行仍由 Project + Product Manager 按 Owner 后续授权安排。

## 验证类别

自动化覆盖真实 Go HTTP/TLS 测试替身、真实 App/SQLite、浏览器桌面与手机、原生 Docker 和独立 Volume 升级。没有真实收费云创建、停止、删除或换 IP，也没有声称实际被墙 IP 已被本功能筛选成功。没有 Owner 国内探针与授权云端目标的完整联调，私人 StackScript IAM、真实来宾脚本执行及四云 IP 更换/账单仍需另行验收。
